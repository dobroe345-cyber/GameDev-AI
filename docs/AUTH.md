# Вход по почте (вместо копирования токена)

Раньше, чтобы подключить интерфейс к серверу, нужно было скопировать `API_TOKEN` из Render. Теперь можно **войти по почте**: вводишь адрес, на него приходит 6-значный код, вводишь код, и всё. Токен остаётся запасным способом (если почта сломалась, он работает всегда).

## Как включить (один раз, ~5 минут, бесплатно)

1. Открой resend.com и зарегистрируйся **почтой, на которую хочешь получать коды** (своей). Бесплатно: 100 писем в день.
2. В Resend: **API Keys** → **Create API Key** → права **Sending access** → скопируй ключ (начинается с `re_`).
3. В Render: сервис `GameDev-AI-1` → **Environment** → **Add Environment Variable**:
   - `MAIL_API_KEY` = ключ из Resend → **Save changes** (сервер перезапустится).
4. Дальше один из двух способов разрешить свою почту:
   - **А. Через токен (проще, если токен уже введён в интерфейсе).** Настройки → Подключение → «Вход по почте» → введи почту → «Получить код». Раз токен уже введён, почта **привяжется** к серверу. Следующий раз токен не понадобится.
   - **Б. Через переменную.** В Render добавь `ALLOWED_EMAILS` = `твоя@почта.com` (можно несколько через запятую). Войти можно сразу, без токена.

## Важное про Resend без своего домена

Пока у тебя нет собственного домена, Resend отправляет письма с адреса `onboarding@resend.dev` и **только на почту, на которую зарегистрирован твой аккаунт Resend**. Для одного владельца этого достаточно. Если понадобится пускать других людей:
- подключи свой домен в Resend (письма тогда можно слать кому угодно) и задай `MAIL_FROM`, например `GameDev AI <ai@твойдомен.com>`;
- либо используй Brevo (бесплатно 300 писем в день, шлёт с подтверждённого адреса): `MAIL_PROVIDER=brevo`, `MAIL_API_KEY=` ключ Brevo, `MAIL_FROM=Имя <твой-подтверждённый@адрес>`.

Если Resend отказывает, в интерфейсе появится понятная причина (например, «Resend без своего домена шлёт только на почту, на которую зарегистрирован аккаунт»).

## Почему не обычная почта (SMTP)

С 26.09.2025 бесплатный Render блокирует исходящие SMTP-порты. Поэтому письма уходят через HTTPS-API почтового сервиса (Resend или Brevo). Пароль от твоей почты серверу не нужен и нигде не вводится.

## Что с безопасностью

- Код одноразовый, действует 10 минут, 5 попыток ввода. На сервере хранится только его хэш, не сам код.
- После входа выдаётся токен сессии (начинается с `gdai_`), действует 90 дней. На сервере хранится только его хэш. Кнопка «Выйти» отзывает сессию на сервере. На одну почту не больше 10 сессий.
- Чужой адрес не отличить от разрешённого по тексту ответа: письмо на него не уходит, а интерфейс говорит то же самое. Оговорка: по времени ответа они чуть отличаются (отправка письма занимает долю секунды), поэтому от очень внимательного наблюдателя это не скрывает.
- Ограничения, чтобы не сжечь бесплатный лимит и не спамить: между письмами на одну почту 45 секунд, не больше 5 в час на почту и 20 в час на весь сервер. Письма на чужие адреса не отправляются и общий лимит не тратят.
- Ключ `MAIL_API_KEY` живёт только в Render. В интерфейс, GitHub и журнал он не попадает.
- Слабое место, которое нельзя полностью убрать: кто знает адрес сервера и твою почту, может до 5 раз в час запросить на неё код. Тебе придут лишние письма, а каждый новый код отменяет предыдущий, так что вход по почте на время может не получаться. Запасной способ (токен) в такой момент работает всегда.

## Если не настроен Neon

Без `DATABASE_URL` сервер хранит сессии в SQLite на временном диске Render. После перезапуска или нового деплоя сессии пропадут, и придётся войти ещё раз (новый код по почте или токен). Чтобы входы пережили перезапуск, подключи Neon: [DEPLOY.md](DEPLOY.md).

## Переменные

| Переменная | Что это | По умолчанию |
|---|---|---|
| `MAIL_API_KEY` | ключ почтового сервиса; без него вход по почте выключен | пусто |
| `MAIL_PROVIDER` | `resend` или `brevo` | `resend` |
| `MAIL_FROM` | от кого письмо | `GameDev AI <onboarding@resend.dev>` |
| `ALLOWED_EMAILS` | какие почты можно пускать (через запятую) | пусто (только привязанные через токен) |

## Проверка

Настройки → Подключение. Если на сервере нет `MAIL_API_KEY`, под блоком «Вход по почте» будет подсказка. Если всё включено, после «Получить код» письмо приходит за несколько секунд (загляни в «Спам»).
